## 🧠 About This Repository

Welcome to **Learning-C**, my personal repository documenting my journey into the C programming language.

This repository is more than a collection of programs. It is a practical record of concepts learned, problems solved, mistakes encountered, and solutions discovered.

The objective is simple:

> Don't just learn how to write code. Understand what happens underneath it.

Through hands-on experimentation, this repository explores programming fundamentals and builds a foundation for understanding computer systems.

## 🎯 Learning Objectives

- Understand the fundamentals of C programming.
- Develop logical and problem-solving abilities.
- Understand memory and pointers.
- Explore how programs interact with computer hardware.
- Write clean, readable, and structured code.
- Build a foundation for Data Structures and Algorithms.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/king-of-hell-roronoazoro/Learning-C.git
```

### 2. Navigate into the project

```bash
cd Learning-C
```

### 3. Compile a C program

```bash
gcc filename.c -o program
```

### 4. Execute the program

**Windows:**

```powershell
.\program.exe
```

**Linux / macOS:**

```bash
./program
```

## ⚙️ How C Compilation Works

One of the most interesting aspects of C is that source code needs to be translated into machine-executable instructions.

```text
       SOURCE CODE
         main.c
            |
            v
       PREPROCESSOR
            |
            v
        COMPILER
            |
            v
        ASSEMBLER
            |
            v
         LINKER
            |
            v
       EXECUTABLE
            |
            v
       PROGRAM RUNS
```

Understanding this process is an important step towards understanding how software works beneath the surface.

## 🌱 The Philosophy

This repository follows three principles:

**01 — Understand, Don't Memorize**

Knowing why something works is more valuable than remembering its syntax.

**02 — Experiment Constantly**

Write code, modify it, test edge cases, and learn from unexpected results.

**03 — Build Strong Foundations**

Mastering fundamentals creates the foundation for more advanced areas of computer science.
